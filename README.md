# SW융합설계 퀴즈 (듀오링고 스타일 학습 앱)

폰에서 이동 중에 푸는 웹 프로그래밍 퀴즈 앱입니다. **빌드 과정 없이** 폴더 그대로 쓰면 됩니다.

- 255문제 · 9개 단원 (HTML/CSS/JS 기초/함수/객체·프로토타입/클래스/이벤트/DOM/콜스택·비동기)
- 유형: **퀴즈** · **코드 채우기** · **결과 예측** (모두 틀리면 이유와 출처 설명)
- 틀린 문제는 같은 세션에서 한 번 더 나오고, **오답노트**에 쌓입니다. 2번 연속 맞히면 "마스터".
- 진행 상황은 브라우저(localStorage)에 저장됩니다. 설정 → 백업에서 내보내기/가져오기 가능.

## 바로 써보기 (PC)
`index.html` 을 더블클릭하면 열립니다. (서버 필요 없음)

## 폰에서 쓰기 — 가장 쉬운 3가지

### 1) Netlify Drop (1분, 가입 불필요에 가까움)
1. https://app.netlify.com/drop 접속
2. 이 폴더(swquiz)를 통째로 끌어다 놓기
3. 나온 주소를 폰 브라우저로 열기 → 공유 메뉴에서 **홈 화면에 추가**

### 2) GitHub Pages
1. GitHub에 새 저장소를 만들고 이 폴더 내용을 올리기 (index.html이 루트에 있어야 함)
2. Settings → Pages → Branch: `main` / root → Save
3. `https://아이디.github.io/저장소이름/` 을 폰에서 열고 홈 화면에 추가

### 3) 같은 와이파이의 PC를 서버로
```
cd swquiz
python3 -m http.server 8000
```
폰에서 `http://PC의IP:8000` 접속. (오프라인 캐시는 https에서만 동작)

> 홈 화면에 추가하면 앱처럼 전체화면으로 열리고, 한 번 열어 두면 **지하철 터널에서도 오프라인**으로 동작합니다(https 호스팅 시).

## 폴더 구조
```
index.html            화면 뼈대
css/style.css         라이트 테마 스타일
js/store.js           진행 상황 저장 (XP·연속일·정답 기록)
js/engine.js          문제 고르기 (틀린 것 > 새 문제 > 덜 익힌 것 > 마스터)
js/hl.js              코드 색칠 (HTML/CSS/JS)
js/ui.js              화면·풀이 흐름·오답노트·설정
data/bank.js          단원 목록 + 문제 만들기 도구 (mc / fb / or)
data/u1.js ~ u9.js    단원별 문제   ← 문제는 여기만 고치면 됩니다
manifest.webmanifest, sw.js, icons/   홈 화면 추가 · 오프라인
tools/validate.js     문제 검증 (정답 번호, 빈칸 수, 코드 실제 실행 결과 대조)
```

## 문제 추가/수정하는 법
`data/u3.js` 처럼 해당 단원 파일을 열고 아래 중 하나를 추가하면 끝입니다.

```js
// 객관식 (정답번호는 0부터, 보기는 앱이 알아서 섞어줍니다)
mc(U, '질문', ['정답', '오답1', '오답2', '오답3'], 0, '해설', '출처',
   { code: '코드(선택)', cat: 'predict', tag: '소주제', x: { 1: '1번 보기를 골랐을 때 추가 설명' },
     run: '실제로 실행해 검증할 코드(선택)' });

// 코드 채우기 (___ 이 빈칸, 정답은 등장 순서대로)
fb(U, '질문', 'const x = ___(1);', ['parseInt'], ['parseInt', 'parse', 'int'], '해설', '출처', { tag: '...' });

// 순서 맞추기 (출력 순서 / 실행 순서)
or(U, '질문', '코드(없으면 null)', ['A', 'C', 'B'], ['D'], '해설', '출처', { run: '검증용 코드' });
```
- 단원을 늘리려면 `data/bank.js` 의 `UNITS` 에 추가하고 `index.html`, `sw.js` 에 새 파일을 한 줄씩 추가하세요.
- 문제 id는 질문+코드 내용으로 자동 생성됩니다. **문구를 고치면 그 문제의 기록은 새로 시작**됩니다.
- 수정 후 `node tools/validate.js` 로 검증할 수 있습니다 (Node 필요, 선택 사항).

## 알아둘 점
- 강의 슬라이드에는 구조 분해 이름 바꾸기가 `{ a=name }` 으로 적혀 있지만, 올바른 문법은 `{ name: a }` 입니다. 앱의 문제는 올바른 문법 기준으로 만들었습니다.
- 기록은 기기·브라우저별로 따로 저장됩니다. 폰을 바꿀 땐 백업을 이용하세요.
